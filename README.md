# Student Management Portal

A simple Student Management Portal built using Node.js, Express.js, EJS, and JavaScript OOP concepts.

## 🚀 Features

- View all students
- Add a new student
- Handle GET and POST requests
- HTML form handling using `req.body`
- Dynamic rendering using EJS
- Student objects created using JavaScript Classes
- Express static files and CSS styling
- Redirect after adding a student

## 🛠️ Technologies Used

- Node.js
- Express.js
- EJS
- JavaScript
- HTML
- CSS
